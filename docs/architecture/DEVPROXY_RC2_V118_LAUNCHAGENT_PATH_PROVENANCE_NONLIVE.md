## Limits that must survive any future integration
- **Do not derive an expected SHA by hashing the same untrusted file being examined**: this would be circular. Expected worker image/source digest must come from independently approved immutable release evidence. V115 live durable product is **not** proved to include V114 signed-refusal fix; don't claim it is current or silently sync it.
- The preflight attests only the entrypoint/binary and private path metadata. It does **not** verify the transitive imported JS modules, the complete release artifact, actual worker process identity, pending HMAC/replay state, Mac background launchd domain, code-signing policy, reboot/login behavior, or owner authorization. An accepted installation still needs an exact release manifest and separately granted one-worker cutover with rollback.
- Homebrew `/opt/homebrew/bin/node` is commonly a symlink; this preflight intentionally rejects unresolved symlinks. The trusted Mac operator must review and pin a canonical, stable **resolved** executable path. Do not silently follow/swap it.
- Private log root must already exist 0700; existing stdout/stderr, if any, must be 0600 regular owner files. No auto-`chmod`, `mkdir`, `unlink`, clean/rotate or install.
- No new `smart-build.sh` hook on this CTO branch because V117 currently owns root build script. Native Mac integration/canonical hook must be reconciled only **after** V117 actual RETURNED and CTO committed diff review, not dispatched concurrently.
- V116's `RunAtLoad=true`, `KeepAlive=false` remains login-once, **not** Docker-late safe or an automatic crash recovery mechanism. No auto-unlink of crash singleton/replay, no restart storm.
