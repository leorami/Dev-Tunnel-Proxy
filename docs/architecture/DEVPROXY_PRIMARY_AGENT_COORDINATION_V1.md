## Optional intelligent parallelism

Before a substantial assignment, the single primary decides whether any genuinely independent specialist would improve throughput. Its explicit status is one of:

- `SPAWNED`: verified provider run ID/identity and observed start, branch/full SHA, narrow objective, owned nonoverlapping files and external state, tests and integration receipt. Creation of a ticket alone is insufficient.
- `NOT_SPAWNED_PROVIDER_UNAVAILABLE`: no supported runtime to actually launch the proposed specialist.
- `NOT_SPAWNED_AUTHORITY_BOUNDARY`: the lane exceeds current approved scope or would collide with private/source/prod state.
- `NOT_SPAWNED_NOT_BENEFICIAL`: dependent, overlapping, too small or riskier to coordinate than to do with the primary.

Each useful specialist lane needs a verified starting SHA, isolated worktree when writing, exact file ownership, dependency/stop conditions, safe tests, a GitHub-linked evidence location and integration owner. Coupled auth, routes, HMAC, Docker, worker, source install and protected Git are not concurrent write lanes. Read-only analysis can proceed without granting new source or production permissions.

The primary keeps owner interruptions at zero by resolving ordinary issues itself. For an owner-only decision, it prepares one consolidated decision-ready question: evidence, smallest grant, risk, rollback and work that can continue. Do not paste secrets or credentials to GitHub; use trusted credential interfaces. An agent never impersonates owner approval.

## Consolidated lifecycle

One genuine STARTED event tied to the exact accepted handoff, then VERIFYING, then one consolidated RETURNED report that distinguishes truly started specialists from proposed ones. Record each contribution, exact commits, tested results, remaining defects, unauthorized operations, and owner UAT boundary. Neither a focused test nor a specialist return closes the primary assignment. A green native test is not proof of running owner Mac code; disk file identity is not process-loaded identity.
