# Dev Proxy — Origin consumer operating contract

Origin is the sole editable universal policy master. The public repository uses the reference lock and project-specific implementation rather than exposing private upstream content. Publish no private Origin material, owner data, credentials, configuration, or private screenshots. The lock is a reference, not a claim of registration or full source/runtime adoption. Read the exact upstream policy through authorized access.

## Coordination and policy uptake

Before every CTO interaction and dispatch, independently read actual GitHub STARTED, RETURNED and STOPPED lifecycle, current branch and full 40-character SHA; reconcile committed changes and original tests. One owner, one CTO, one primary Cursor Engineer-I. The primary alone owns integration, conditional nonoverlapping specialist work and one consolidated terminal receipt. Report real provider identities and starts, or why not spawned. A GitHub issue or draft PR is not execution or authority. Never interrupt an active primary or re-dispatch a completed task.

At each safe boundary check Origin's current published master, registry and exact source-linked notices. Apply binding owner directives even while upstream candidate PRs await publication; distinguish these from merged policy. Delivery target 15 minutes from publication, acknowledge within 24 hours, uncomplicated incorporation within 48 hours. Record exact release digest, source SHA, disposition and blockers; escalate to CTO and Origin without owner courier. Acknowledgment is not incorporation; verified adoption requires actual source, scoped tests, independent review and normal app parity when applicable. No public mirror of the private Core and no automatic merge, deployment, credential or authorization change. Request registration through Origin's existing notifier; do not create an alternate polling service.
